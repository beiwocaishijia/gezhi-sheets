# 格知 AI 使用与开发说明

## 开始使用

1. 在项目目录运行 `npm ci`、`npm run dev`，打开 <http://127.0.0.1:8001>。生产方式为 `npm run build:app` 后 `npm start`。
2. 点击“模型设置”，在五家独立配置卡片中选择一家，填入该厂商的 API Key 和模型 ID。
3. 点击“保存并测试连接”。它会进行一次真实的小请求，验证响应是否符合 JSON 协议，可能产生少量费用。失败时会区分密钥、额度、权限、限流、超时和输出格式问题。
4. 加载反馈示例，拖选需要处理的单元格，或明确切换“整张工作表”。当前范围显示实际行数、列与坐标。
5. 选择任务，填写要求，生成并检查预览。点击“应用”才会写入；顶部“撤销”或 `Ctrl+Z` 可一次恢复，`Ctrl+Shift+Z` 重做。

模型可从预设中搜索，也可手动填写。支持列表接口的厂商可以“获取模型列表”。预设列表不表示模型已对你的账户开放；不自动换厂商。顶部记住每家最近选择的模型。真实连接状态仅对测试过的当前模型显示。

## 六类任务

### 批量填列

提供提取、分类、摘要、翻译及自定义预设。多个输出字段用中文或英文逗号分隔。默认添加结果列，选择已有列会预览原内容与覆盖值。结果用不可变的原行标识对应，拒绝缺行、重复行、越界行与字段数不符的响应。

原文缺少依据时要求模型返回空值，预览显示“未提供”。这是模型约束和人工审核共同完成的语义检查；格式校验不能证明内容真实。普通 AI 内容始终按文本保存，包括 `=SUM(1,2)` 这样的字符串。

### 文字转表

粘贴文字，生成列名和记录。在“编辑完整预览”中修改内容；每页 25 行，可以翻页。确认后新建一张工作表，或把每个生成字段映射到不同的现有列后追加。缺失值保留为空，金额等计算可再用公式助手完成。

### 整理数据

名称统一直接提出单元格修改建议；信息拆分使用多个新输出列。缺失提示和疑似重复新增“整理建议”列并标色，不补造缺失值、不删除原记录。完整预览显示原值、建议与理由，取消勾选即可排除建议。

疑似重复除了当前批次，还会提供选区内其他批次中相似度较高的候选。候选检索是启发式方法，不保证发现所有重复；模型的“疑似”也必须人工确认。每次发送的目标记录与对照记录合计不超过 20 行，传递完整单元格值。

### 表格问答

内容归纳会逐批读取选区并汇总所有批次，显示覆盖行数和依据行。精确统计先生成受限查询计划，程序执行筛选、分组、计数、求和、平均、极值、排序和前 N 项。模型不能执行任意代码。

统计使用 Decimal 计算十进制数字。缺失值、公式报错和非数字文本不作为 0；全组无有效数字时返回空值。`count` 未指定列表示记录数，指定列表示非空值数；数值统计跳过数量按单元格去重显示。

### 公式助手

根据列名、选区首行值与原公式生成或解释。程序把首行公式向选中行填充，保留绝对引用，逐行显示试算结果。若任一行出现循环引用、除零或不支持语法，阻止应用并说明位置。表格显示、试算、导出缓存和统计使用同一解析器。

白名单：`SUM AVERAGE MIN MAX COUNT COUNTA IF ROUND ABS AND OR NOT`，以及算术、比较、字符串 `&` 连接和当前工作表的 A1 引用/范围。支持 `$A$1` 等绝对引用。不执行模型返回的 JavaScript；不支持跨表/外部工作簿引用、动态数组、Excel 全部函数或宏。

解释或排错可能仅返回说明，此时不会出现“应用”按钮。普通文本前加一个单引号可以显式标记文本，显示和引用时不带这个标记；如需显示原文自带的单引号，再添加一个单引号。

### 自然语言操作

支持新增列、追加记录、指定单元格填值、条件填值、整行排序与条件标色。模型只生成列与范围对应的操作计划，条件由程序逐行检查，不能执行任意脚本。条件不明确时在面板追问。

排序要求明确选择整张工作表，移动完整记录和样式；同一计划后续按行标识填值仍对应排序前的原记录。新增、排序等结构操作遇到合并单元格会阻止执行，不自动取消合并。只读列和只读单元格不接受 AI 值或样式修改。

## 文件、保存与恢复

- `.xlsx` 使用 ExcelJS；CSV 使用 Papa Parse。导入先预览工作表、列标题、类型和前 5 行，可以取消“首行作为标题”或只选部分工作表。CSV 默认按文本导入，保留前导零；统计和公式计算可以读取数字文本。
- Excel 导出包含多工作表、列标题、数据和支持的公式。标题占据 Excel 第 1 行，因此导入/导出会同步调整相对及绝对引用。不支持的导入公式使用可用缓存值并提示；没有缓存时为空。
- 不保证宏、图表、富文本和复杂排版完整还原。CSV 本身没有类型信息，其他软件打开时可能自动转型；需要在 Excel 中保持编号文本类型时优先使用 `.xlsx`。CSV 导出会对公式危险前缀加文本转义。
- 自动保存防抖 600 毫秒，使用版本号检查与原子替换，保留上一份有效工作簿 `.bak`。生成任务前先保存快照；期间编辑、插删、排序或撤销后旧预览失效。
- 保存失败显示“保存失败 · 点击重试”，不会宣称已保存。发生其他窗口版本冲突时不要强行覆盖：先导出当前 Excel 留存，再刷新读取本机最新版本。
- 撤销/重做历史保留在当前打开的页面内，刷新后恢复工作簿内容，不恢复此前撤销栈。
- 单批最多 20 行、按输入字符大小继续拆分，最多两个请求并发。超长单行明确报错，不静默截断。仅 429 和暂时性服务错误自动重试最多两次；失败任务可只重试未完成批次。取消后忽略迟到结果。

## 模型配置

| 厂商 | 官方普通 API 默认地址 | 说明 |
| --- | --- | --- |
| GLM | `https://open.bigmodel.cn/api/paas/v4` | [官方兼容接口](https://docs.bigmodel.cn/cn/guide/develop/openai/introduction)，首版预设与手填模型 |
| Kimi | `https://api.moonshot.cn/v1` | [Chat API](https://platform.kimi.com/docs/api/chat)，可读取模型列表 |
| 豆包 | `https://ark.cn-beijing.volces.com/api/v3` | [方舟 Chat API](https://ark.volcengine.com/region:cn-beijing/docs/chat-api)，支持 Model ID 或 `ep-` 接入点 ID |
| DeepSeek | `https://api.deepseek.com` | [官方接口](https://api-docs.deepseek.com/)，支持模型列表 |
| Qwen | `https://dashscope.aliyuncs.com/compatible-mode/v1` | [百炼兼容接口](https://help.aliyun.com/zh/model-studio/compatibility-of-openai-with-dashscope)，高级设置支持官方地域与工作空间地址，Key 必须匹配地域 |

本地服务仅连接官方允许的 HTTPS 地址，不跟随重定向。按模型名称设置已知的 JSON 和关闭思考参数；未知/自定义模型使用基本兼容协议。如模型不支持 JSON 模式，可以在高级设置切换“仅提示词约束”，返回结果仍然经过 Zod 严格校验。

真实联通与小批量业务结果需要使用各家的实际账户验证。仓库内协议模拟测试验证适配器行为，不代表任一账户有权限或余额，也不代表真实模型必然遵循任务要求。

## 本机数据与安全边界

默认目录 `%LOCALAPPDATA%\CE-Lab`（沿用升级前的目录，已有工作簿与密钥无需迁移）：

```text
providers.json          # DPAPI 密文、脱敏尾号、模型与验证状态
workbooks/<uuid>.json    # 工作簿、数据版本
workbooks/<uuid>.json.bak
jobs/<uuid>.json         # 任务快照、批次进度和结果，方便失败重试
```

加密绑定当前 Windows 用户。其他机器或 Windows 用户无法直接解密，迁移后重新填写 Key；加密不可用时失败并提示，不保存明文。密钥不写入 localStorage、sessionStorage、导出文件或日志。删除密钥后不保留旧密钥备份。工作簿和任务是本机 JSON 文件，备份时妥善保管。

首版只监听 `127.0.0.1`，不提供登录、多人协作或公网部署。接口校验 Host/Origin 与 JSON 内容类型。端口通过 `PORT` 覆盖，数据目录可通过 `CE_LAB_DATA_DIR` 覆盖；日常使用默认 8001。端口占用会报错，不自动结束其他程序。

## 开发结构与接口

- `app/`：原生 JavaScript 工作台、文件、修改预览与工作簿撤销栈。
- `shared/`：Zod 契约、无代码执行的公式解析器、统计与候选匹配。
- `server/`：Express 本地 API、DPAPI、原子保存、厂商流式适配、任务队列。
- `src/utils/history.js`：同步 `worksheet.batch(callback)`，组合历史、异常回滚、完整撤销/重做。回调必须同步，使用组件提供的历史可记录修改方法，不直接改内部对象。
- `formulaEvaluator`：可选组件配置项，工作台传入安全解析器，原组件默认行为兼容。

| 路由 | 方法 | 内容 |
| --- | --- | --- |
| `/api/providers` | GET | 五家目录与脱敏配置状态 |
| `/api/providers/:id` | PUT / DELETE | 加密保存、更新或删除 Key |
| `/api/providers/:id/models`、`/test` | GET / POST | 模型列表、真实连接测试 |
| `/api/workbooks` | GET / POST | 列表、创建 |
| `/api/workbooks/:id` | GET / PUT | 读取、带 revision 保存/重命名 |
| `/api/ai/jobs` | POST | 创建任务，固定工作簿版本与范围 |
| `/api/ai/jobs/:id` | GET | 脱离流式连接读取状态和结果 |
| `/api/ai/jobs/:id/events` | GET | SSE 进度与最终结果 |
| `/api/ai/jobs/:id/cancel`、`/retry` | POST | 取消、仅重试未完成批次 |
